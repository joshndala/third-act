# The Third Act — Landing Page 🎨

A modern marketing site for *The Third Act* movie journal.

## Tech Stack
- **Vue.js 3** & **Vite**
- **Vue Router** for navigation
- **Vanilla CSS** with brand design system

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Run dev server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
